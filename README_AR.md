# NOVA AI

هذا مشروع واجهة عربية لمساعد ذكاء اصطناعي، مع خادم Node.js يتصل بواجهة OpenAI API ويحافظ على سرية مفتاح API على الخادم.

## تريد نشر الموقع على الإنترنت؟
اقرأ الملف **`دليل_النشر_على_الإنترنت.md`** واتبع الخطوات بالترتيب. يوجد ملف `render.yaml` جاهز لمساعدة Render على إعداد الخدمة.

## تشغيل محلي على Windows
1. ثبّت Node.js 18.17 أو أحدث من https://nodejs.org
2. فك ضغط المشروع.
3. شغّل `تشغيل_NOVA.bat`.
4. اتبع التعليمات لإضافة مفتاح API في ملف `.env` محليًا، ثم افتح `http://localhost:3000`.

## ملاحظات
- المحادثة الحقيقية تتطلب مفتاح OpenAI API صالحًا مع توفر الوصول/الرصيد المناسب.
- استخدام OpenAI API يُحاسب بشكل منفصل عن اشتراك ChatGPT.
- لا ترفع ملف `.env` إلى GitHub ولا تضع مفتاح API في الواجهة.
